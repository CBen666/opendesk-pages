OpenDesk 的端侧知识库就是 **智能文件系统**——桌面版左下角的「文件系统」页面。它会把你指定的本地目录扫描、解析并建立索引，让智能体能够按语义检索你的本地文档，相当于一个完全存储在本机的私有知识库。

与云端知识库不同，智能文件系统的文件内容不出设备：文档在本地解析、切分并向量化，索引也保存在本地。

## 工作原理

智能文件系统对每个扫描目录执行以下流程：

1. **扫描**：按包含/排除模式遍历目录，监听文件变化；
2. **解析**：提取文档正文（支持 `.txt`、`.md`、`.pdf`、`.doc/docx`、`.ppt/pptx`、`.xls/xlsx`、`.odt/.ods`、`.csv`、`.json`、`.yaml`、`.xml`、`.html`、`.css`、`.js/.ts` 等常见格式）；
3. **向量化**：用你配置的**向量嵌入模型**把文本片段转成向量；
4. **索引**：元数据与向量都写入本地索引库。

之后智能体在对话中就能调用「语义搜索」工具，按含义而不是关键词找到相关文件片段。没有配置嵌入模型时系统会退化为**基础索引**模式：仍会记录文件清单，可以按文件名/标题查找，但没有语义理解能力。

## 配置默认向量嵌入模型

参考 [初始化配置](/docs/introduction/config/) 的步骤，配置默认的向量嵌入模型。

## 在桌面端配置

1. 点击左下角工具栏的「文件系统」进入智能文件系统页面；
2. 在文件树中**勾选你想让 AI 理解的文件夹**，勾选即成为数据源，无需其他操作；
3. 页面顶部会实时显示状态（未配置 / 正在启动 / 运行中 / 查询模式）和索引模式（完整索引 / 基础索引），以及各数据源的扫描进度（如"扫描中 · 1200 / 5000 文件"）。

当前**工作空间会被自动纳入**索引范围，且不能在此移除；要变更请回主页面切换工作空间。

页面上还可以对这些数据源做日常管理：

| 操作 | 说明 |
| --- | --- |
| 暂停 / 继续扫描 | 临时停掉某个目录的扫描，不影响已建索引 |
| 立即扫描新文件 | 手动触发一次增量扫描，不必等待自动轮询 |
| 移除扫描路径 | 不再索引该目录，不会删除你的文件 |
| 重置智能文件系统 | 清除 AI 已建立的全部文件索引，之后重新整理 |

## 使用端侧知识库

配置完成后无需任何特殊语法，直接提问即可，智能体会自动调用语义搜索：

```
我记得有一份项目预算的文档，帮我找出来并总结要点
```

```
从我的本地文档里查一下产品需求里关于登录功能的要求
```

如果希望限定搜索范围，可以先在文件系统页面勾选具体目录，或在提问中指明文件夹路径。

## 常见问题

**页面提示"未配置嵌入模型"或"嵌入模型不可用"？**

语义检索不可用，系统处于基础索引模式。按上文配置一个 1024 维的向量嵌入模型后，索引会自动重建。

**有些文件没有被语义理解？**

过大或格式不适合解析的文件（如扫描件 PDF）不会生成语义索引，但仍能通过文件名搜到。页面会提示"N 个文件无法理解"。

**提示"语义理解已达到当前设备上限"？**

本地向量容量有限，新文件会继续记录文件清单，已有语义结果仍可搜索。可以移除不重要的扫描目录释放容量。

**换了嵌入模型会怎样？**

嵌入配置变更会触发索引自动重建，重建期间部分文件可能暂时只有基础索引。

**文件内容会上传吗？**

不会。扫描、解析和索引都在本机完成，发送给大模型的只有检索命中的相关片段。
